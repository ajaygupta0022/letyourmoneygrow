# 🌱 Grow Your Money

Welcome to the **Grow Your Money** repository! 

Grow Your Money is a premium wealth management platform built to provide a dynamic, high-conviction advisory experience. It features intuitive portfolio tracking, performance analytics, and institutional-grade tools to help proactive investors manage and grow their financial assets.

**🌐 Live Website:** [https://letyourmoneygrow.in](https://letyourmoneygrow.in)

---

## ✨ Key Features
- **Dynamic Dashboard & Analytics:** Real-time metrics and portfolio tracking.
- **Financial Calculators:** Built-in tools to help estimate returns and plan wealth strategies.
- **Financial Health Check:** Interactive assessments for your financial well-being.
- **Modern & Responsive UI:** Built with React, Tailwind CSS, and Framer Motion for a seamless experience on all devices.
- **Secure & Fast:** Backend powered by Node.js for quick and secure data handling.

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Express.js
- **Deployment:** Hostinger

## 🚀 Local Setup & Installation

If you want to run this project locally, follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com/ajaygupta0022/letyourmoneygrow.git
cd letyourmoneygrow
```

### 2. Frontend Setup (Client)
```bash
cd Client
npm install
npm run dev
```
*The frontend will start at `http://localhost:5173/`*

### 3. Backend Setup (Server)
Open a new terminal window:
```bash
cd Backend
npm install
npm run dev  # or 'node Server.js'
```
